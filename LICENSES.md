# Asset licence register

One line per asset. If it isn't here, it doesn't ship.

| Path | Source | Licence | Author / owner | Date added | Notes |
|---|---|---|---|---|---|
| `components/*.js`, `scenes/server-hall/*` | Written for this channel | Own work | Sam (de-tech-ify) | 2026-11-05 | Procedural: geometry, textures and lights generated in code |
| `three` (npm dependency, not committed) | threejs.org | MIT | three.js authors | 2026-11-05 | Installed via npm |

## Allowed sources
- Our own code, renders and screenshots (scrubbed)
- Claude-drafted code and procedural assets made for this channel
- CC0: Kenney, Quaternius, Poly Haven, ambientCG
- Anything else only with a written licence note in a row above

## Not allowed
- Frames, models, logos or scripts from other creators
- Brand logos and product photos we don't own
- Screenshots containing real IPs, hostnames, tokens, usernames or client data
