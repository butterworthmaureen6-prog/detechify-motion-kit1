# ui/screenshots: universal background library

All the images Claude Design may use as backgrounds and as stills to animate live here, in one flat folder (no per-topic folders).

- `CATALOG.md` lists every image with subject, palette, accent colour, mood and tags. It is the index the skill and Claude Design read. Keep it in sync.
- Generate the first set with `prompts/gemini-background-pack.md` (35 images, each a different environment and colour theme).
- All images are 9:16 portrait for now. File names: `bg-NN-short-name.jpg`. Landscape twins (`-16x9.jpg`) come later if needed.
- JPG, quality about 85, under about 800 KB each.

Rules: only images you generated or own; no text, logos or people in them; no other creators' frames; nothing showing real IPs, hostnames or client data.
