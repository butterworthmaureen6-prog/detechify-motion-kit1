# Topic: AI, LLMs and agents

Use for: how models work, tokens, context windows, RAG, agents, tool calls, prompts, model routing, costs.

## Set (environment)
Dark violet-tinted studio. A **glowing lattice of nodes** for models, glass tiles for tokens, a long glass tube for the context window. Agents are distinct glowing nodes passing messages.

## Light and colour
- Preset: `ai_violet` (violet key, mint accent).
- Tokens = small glass tiles in cyan. Active reasoning = violet pulse through the lattice. Cost/budget = amber. Success = mint.

## Hero objects
- Token stream: tiles flowing along a rail, each with a short text fragment.
- Context window: a long glass tube that fills with tiles. When it is full, old tiles drop out the far end.
- Agent nodes with names, linked by light cables. Tool calls as small satellites that fly out and return with a result.
- Spend meter: a glass panel with a counter that ticks up as tokens flow (use for token-cost videos).
- GPU cluster: reuse the rack component from `components/rack.js` in a violet light.

## Motion vocabulary
- A prompt enters as a stream of tiles, the lattice lights up layer by layer, an answer streams out tile by tile.
- RAG: a query tile travels to a document shelf, comes back with matching pages attached.
- Routing: tiles split at a gate, each lane labelled with the model that handles it.

## Camera
- Slow orbit-style pushes around the lattice are allowed (still ease-out bursts). Rise to reveal scale.
- Recipes: `hold-push`, `follow-packet` (follow a token), `rise-reveal`, `screen-dive` (into a chat window).

## Text layer
- Keyword cards: terms and numbers ("Context window", "128k tokens", "Cheapest model that works").
- 3D labels pinned to nodes and tiles ("system prompt", "tool call", "retrieved chunk").

## Screens to supply (scrubbed)
- Chat UI, agent terminal output, a cost dashboard, a trace view.

## Avoid
- Humanoid robots, glowing brains, clip-art circuit boards.
- Specific model benchmark numbers unless the script states them.
