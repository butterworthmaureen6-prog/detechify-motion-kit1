# Topic: data cleaning / data engineering

Use for: raw data, messy data, duplicates, nulls, formats, ETL, SQL cleaning, Bronze/Silver/Gold layers, data quality.

## Set (environment)
Dark glossy studio. The hero is a **glass data table** floating above the reflective floor, a few dim tables drifting far behind for depth. Real text in the cells (names, dates, amounts), readable at screen size.

## Light and colour
- Preset: `studio_data` (amber accent, calm cyan rim). Shift to `alert_red` while the video says the data is wrong, back to `studio_data` when it is fixed.
- Issue colours: duplicate = amber row tint. Missing = red cell with dashed outline. Wrong format = violet outline. Fixed = brief green flash, then calm.
- Clean state: green left bar on verified rows, header chip turns green.

## Hero objects
- Glass table slab (5 x 3 m landscape, 3 x 4.5 m portrait with fewer columns).
- Scanner beam: a thin glowing bar that sweeps down the table, cyan to detect, green to verify.
- Issue counter chip in the table header ("Issues: 11" counting down to 0) and a row counter ("Rows: 10" to "6").
- Medallion layers (when the script says Bronze/Silver/Gold): three stacked slabs in copper, silver and gold metal, the table moving up through them.

## Motion vocabulary
- Duplicate rows slide sideways, fade, then the gap closes.
- Dropped rows slide out in red. Filled cells crossfade to the new value with a green flash.
- Format fixes crossfade old text to new text cell by cell, top to bottom, with a cyan flash.
- Scanner passes over the whole table once to detect, once more to verify.

## Camera
- Wide low establishing shot, push in as the scanner starts, close to the rows being fixed, pull back and rise on "clean".
- Recipes: `hold-push`, `burst-reframe`, `rise-reveal`.
- Portrait: pull the camera back about 1.75x so a full row fits the frame width.

## Text layer
- Keyword cards: the issue types ("Duplicates", "Missing values", "Standardise", "Clean data").
- 3D labels pinned to cells: "duplicate row", "blank", "different format". Place pills outside the slab edge.
- Captions at the bottom as usual.

## Screens to supply (scrubbed)
- A messy CSV or SQL result, a before/after query, a profiling report.

## Avoid
- Invented numbers presented as real results. Say "example data" when values are made up.
- Cells too small to read.
